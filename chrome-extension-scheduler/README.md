# CalAutobot Scheduler Chrome Extension

A lightweight Chrome extension that injects "Insert availability" and "Insert booking link" buttons directly into Gmail compose windows. It reuses the `/api/extension/availability_text` and `/api/extension/booking_link` endpoints added to the server.

## Features
- Inserts plain-text availability snippets generated by CalAutobot.
- Inserts the user’s public booking link.
- Automatically syncs email recipients as contacts before each send.
- Works entirely inside Gmail—no extra pop-ups.
- Requires only two host permissions: `https://mail.google.com/*` and `https://calautobot.com/*`.

## Prerequisites
1. You must already be logged into https://calautobot.com in the same Chrome profile so the extension can reuse the session cookie.
2. Your CalAutobot account must have at least one public event type (slug + handle) for booking links.

## Local Installation
1. Build/run the CalAutobot server with the new `/api/extension/*` routes.
2. In Chrome, open `chrome://extensions`.
3. Enable **Developer mode**.
4. Click **Load unpacked** and select the `chrome-extension-scheduler` folder.
5. Open Gmail in the same profile. When composing an email, the buttons should appear above the message body.

## How it works
- A content script (`content.js`) watches for Gmail compose editors and injects the button panel.
- When clicked, the panel calls CalAutobot’s extension APIs with `credentials: 'include'`, so the user must be logged into CalAutobot.
- The API responses contain formatted text/links, which are inserted into Gmail via `document.execCommand('insertText', …)`.

## Development notes
- To point at a non-production CalAutobot host, change `API_BASE` at the top of `content.js`.
- The extension never stores credentials; it depends on the CalAutobot session cookie or, if desired, you can extend it to send a `user_email`+token pair.
- Permissions are deliberately minimal. If future features require other domains, add them to `host_permissions` in `manifest.json`.
